# 原始数据及固定划分

默认从相邻的 `癌症基因表达数据可视化/原始数据/TCGA-PANCAN-HiSeq-801x20531.tar` 只读加载原始 CSV，绝不读取其探索性统计、Top50基因、PCA坐标或 Z-score。

如需将本项目单独复制到另一台电脑，可将原始 `data.csv`、`labels.csv` 放在本目录，或使用 `python main.py --archive "实际压缩包路径"`。无需解压TAR，程序会搜索任意目录层级。

首次执行第一阶段会写入 `split_manifest.json`，固定开发集和保留测试集的样本ID、种子及完整数据指纹。以后运行必须匹配这份清单；数据或划分设置改变时会明确报错，不能悄悄换测试集。

每轮结果目录中保存清单副本以便审计。本目录的固定清单不包含测试预测或测试得分。请保留清单，后续所有阶段复用同一划分。
